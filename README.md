# One-Line Laugh Entry

A tiny TypeScript program that writes a single funny line to `entry.txt` for the [make.fun](https://make.fun) "One-Line Laugh" bounty.

## Usage

```bash
# Default output to /output/entry.txt
node main.ts

# Custom output directory
MAKEFUN_OUTPUT_DIR=/tmp/my-output node main.ts
```
